# Contributing to 光影纸境

Thanks for helping improve Light Paper Realm.

## What to contribute

- A Licowa wallpaper case: source wallpaper and its generated 3:4 result.
- A verified cross-platform prompt adjustment.
- Documentation, translation, or an issue report.

## Example submission checklist

1. Place the original in `examples/source/` and the generated result in `examples/output/`.
2. Use a descriptive `licowa-<scene>.jpg` / `licowa-<scene>-light-paper-realm.png` file pair.
3. Confirm the result is portrait 3:4, has an exact 50:50 split, and has no newly generated text, logo, watermark, or signature.
4. Add the source page and theme to `docs/THIRD_PARTY_NOTICES.md`.
5. Do not submit personal photos, private information, or assets without a public source and appropriate reuse rights.

## Prompt changes

Keep the non-negotiable visual system intact: source-faithful upper half, handmade paper lower half, exact split, and no new readable text. Explain the observed failure and the narrow change that addresses it.
